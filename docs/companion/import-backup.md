# Import, Export, and Backup

DnDino Hero stores data locally on the device.

Import, export, and backup features help protect and move content.

## Import from DnDino

The app can import JSON files produced by DnDino for:

- spells
- feats
- rules
- classes
- species
- backgrounds

This lets you prepare or store content in DnDino and then move it to the player's sheet.

## Export

The same content can be exported from DnDino Hero.

Export is useful to:

- transfer data to another device
- create a manual copy
- share a custom class, species, or background
- reuse content between installations

## iCloud Backup

In settings, you can enable iCloud backup.

Backup is designed as a full copy of the app database.

When there are no characters and the app finds an available backup, it can offer to restore it.

The app can also create a backup when it goes to the background or is closed. On launch, it checks for a newer backup and, depending on settings, can restore automatically, ask for confirmation, or leave control manual.

!!! warning
    Restore replaces local data with the data in the backup. Use it only when you really want to recover that copy.

!!! note
    The active character selection stays local to the device. This lets two devices with the same iCloud account keep different active characters selected.

## Images

Images linked to characters are copied inside the app.

When you delete an image record, the linked file should be removed too. This avoids leaving unused images in the app storage.

Custom attack icons are saved in a form suitable for the app, so very large original images do not need to be kept.

## DnDino Links

The local DnDino connection does not replace iCloud backup.

Backup protects or moves app data. The DnDino connection is for the game session: it links a Hero device to an active adventure, synchronizes character state, and enables private DM chat.

If a link is no longer correct, DnDino can remove saved associations and Hero can try to connect again.

## Practical Tips

- enable iCloud if you want automatic data protection
- manually export important content before major changes
- import reusable content once, then associate it with characters
- avoid duplicates if you want to keep classes, species, backgrounds, and spells organized
