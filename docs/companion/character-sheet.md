# Character Sheet

The character sheet is the center of DnDino Hero.

It is divided into sections so you can focus on one part without constantly scrolling through the whole sheet.

## Main Sections

The main sections are:

- **Complete Sheet**
- **Identity**
- **Characteristics**
- **Skills and Saving Throws**
- **Species and Background**
- **Class**
- **Spells**
- **Attacks**
- **Feats**
- **Equipment**
- **Conditions**
- **Notes**
- **Combat**
- **Private Message to DM**, when the character is connected to DnDino

## Identity

The **Identity** section contains the descriptive and narrative data of the character.

You can manage:

- name
- player name
- deity
- alignment
- cover image
- linked character images
- spoken languages
- appearance
- personality traits
- story
- notes

Class level progression is managed through the class path, so multiclass characters remain ordered.

The player name is also used in the DnDino connection so the DM can identify the player and device more easily.

## Characteristics

The **Characteristics** section collects the most common mechanical values:

- ability scores
- skills
- saving throws
- hit points
- armor class
- initiative
- speed
- Heroic Inspiration
- hit dice

Bonuses are modular. When needed, you can add fixed bonuses, ability modifiers, proficiency, or class progressions.

## Hit Points

The hit point panel manages:

- maximum HP
- current HP
- temporary HP
- healing
- damage
- short rest
- long rest
- available hit dice
- death saving throws

When the character drops to 0 HP, the sheet shows death saving throws.

## Armor Class

Armor class is built from multiple parts:

- base value
- ability modifiers
- armor
- shield
- other bonuses

The panel can show a different image depending on the setup: armor, shield, or agile dodging.

## Multiclass

The total character level is the sum of all class levels.

When you level up, you choose which class advances. When you reduce the level, the app removes the last inserted class level and preserves the progression order.

!!! note
    Proficiency bonus depends on total character level, not on the level of a single class.

## Combat

The **Combat** section shows the most useful information during an encounter:

- character state
- hit points
- armor class
- initiative
- speed
- saving throws
- conditions
- attacks
- prepared spells
- spell slots
- relevant features and resources

It is designed to reduce scrolling during play.

## Attacks

The **Attacks** section lets you create weapon attacks.

Each attack can include:

- name and icon
- custom imported icon
- weapon properties
- mastery and mastery description
- proficiency
- ability used for the attack roll
- fixed, ability, proficiency, or progression bonuses
- main damage
- additional damage
- damage type

Die or bonus class progressions can be used in damage and bonuses when needed.

## Equipment

Equipment includes coins, weapons, armor, tools, and items.

Lists are compact and organized by category. Each entry can have quantity, cost, weight, description, and category-specific fields.

DnDino Hero also tracks **attunement**:

- you can set the maximum number of attuned items
- an item can require attunement
- only items that require attunement show the attunement control
- once the limit is reached, no more items can be attuned

## Notes

Notes can have a title, category, and text.

You can also use handwriting or pencil input. The drawing area can use plain, ruled, or grid paper, and drawing tools can be shown or hidden.
