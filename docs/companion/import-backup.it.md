# Import, export e backup

DnDino Hero salva i dati localmente sul dispositivo.

Per proteggere e spostare i contenuti sono previste funzioni di importazione, esportazione e backup.

## Importazione da DnDino

L'app può importare file JSON prodotti da DnDino per:

- incantesimi
- talenti
- regole
- classi
- specie
- background

Questo permette di preparare o conservare contenuti in DnDino e poi portarli nella scheda del giocatore.

## Esportazione

Gli stessi contenuti possono essere esportati da DnDino Hero.

L'esportazione serve per:

- trasferire dati su un altro dispositivo
- creare una copia manuale
- condividere una classe, una specie o un background personalizzato
- riutilizzare contenuti tra più installazioni

## Backup iCloud

Nelle impostazioni puoi abilitare il backup iCloud.

Il backup è pensato come copia completa del database dell'app.

Quando non ci sono personaggi e l'app trova un backup disponibile, può proporre il ripristino.

L'app può eseguire un backup quando viene mandata in background o chiusa. All'avvio controlla se esiste un backup più recente e, in base alle impostazioni, può ripristinarlo automaticamente, chiedere conferma o lasciare il controllo manuale.

!!! warning
    Il ripristino sostituisce i dati locali con quelli presenti nel backup. Usalo solo quando vuoi davvero recuperare quella copia.

!!! note
    La scelta del personaggio attivo resta locale al dispositivo. Questo permette di usare due dispositivi con lo stesso account iCloud mantenendo selezionati personaggi diversi.

## Immagini

Le immagini associate ai personaggi vengono copiate dentro l'app.

Quando elimini il record di un'immagine, anche il file collegato deve essere rimosso. Questo evita di lasciare immagini orfane inutili nello spazio dell'app.

Le icone personalizzate degli attacchi vengono salvate in una forma adatta all'app, così non serve conservare immagini originali troppo grandi.

## Collegamenti con DnDino

Il collegamento locale con DnDino non sostituisce il backup iCloud.

Il backup serve a proteggere o spostare i dati dell'app. Il collegamento con DnDino serve invece alla sessione di gioco: associa un dispositivo Hero a un'avventura attiva, sincronizza lo stato del personaggio e abilita la chat privata con il DM.

Se un collegamento non è più corretto, DnDino può rimuovere le associazioni salvate e Hero può tentare di collegarsi di nuovo.

## Consigli pratici

- abilita iCloud se vuoi una protezione automatica dei dati
- esporta manualmente contenuti importanti prima di grandi modifiche
- importa contenuti riutilizzabili una volta sola e poi associali ai personaggi
- evita duplicati se vuoi mantenere ordinate classi, specie, background e incantesimi
